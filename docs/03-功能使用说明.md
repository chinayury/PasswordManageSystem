# 03 - 功能使用说明

> 更新日期：2026-11-14
> 适用：密码管理系统 PasswordManageSystem（PDM）

本文档说明各入口的用法、参数与已知限制。系统为 Web 应用，所有功能通过浏览器访问，
按角色分为普通用户与管理员。

## 1. 访问入口

部署完成后，浏览器打开部署地址（Docker 默认 `http://服务器IP:6084`，源码运行默认
`http://127.0.0.1:8000` 或 `:5000`）。

- 初始管理员：`admin / admin123`，**首次登录后系统持续警示直至修改口令**。
- 是否开放自注册由 `ALLOW_REGISTER` 控制（默认 `true`）。

## 2. 认证与会话

| 功能 | 说明 |
|---|---|
| 登录 | 用户名 + 密码；开启两步验证时需额外输入 TOTP 动态码 |
| 注册 | 邮箱验证码注册（需配置 SMTP，否则不可用） |
| 找回密码 | 邮箱验证码重置（需配置 SMTP） |
| 记住我 | 勾选后 7 天内免重复登录；重新认证时会强制走一次完整登录 |
| 强制改密 | 管理员重置/新建的账号登录后，除改密/登出外一律重定向到改密页 |
| 全设备踢下线 | 改密/重置/注销后，其它设备的会话纪元落后，强制登出 |
| 空闲自动锁定 | 设 `SESSION_IDLE_MINUTES>0` 时，会话连续空闲超时强制重新登录（默认关闭） |

**已知限制**：邮件验证码功能依赖 SMTP 配置，未配置时注册/找回密码不可用（明确报错，
不崩溃）。

## 3. 两步验证（TOTP）

- 自助开启/关闭，需"当前密码 + 动态码"双重确认。
- 开启时展示 10 个一次性恢复码，**仅展示一次**，请妥善保存；恢复码只存 bcrypt 哈希。
- **已开启时禁止重新生成密钥**，杜绝一次点击静默关闭 2FA。
- 半登录状态有效期 10 分钟。

## 4. 密码记录

- **字段**：设备台账式 12 字段（如名称、用户名、密码、地址、备注等）。
- **加密**：密码字段 Fernet 应用层加密落库；查看明文时按需解密，限流 60 次/分钟。
- **搜索与分页**：支持多字段搜索与分页（每页 `RECORDS_PER_PAGE`，默认 20）。
- **到期关注**：快捷筛选"30 天内到期 / 已过期"。
- **回收站**：软删除，支持恢复与彻底删除。
- **附件**：单条记录支持双附件上传（扩展名受 `ALLOWED_UPLOAD_EXTENSIONS` 限制）。
- **密码生成器**：随机字符（长度/字符集开关/排除易混淆字符）与易记口令短语（词数/
  大写/附加数字可选）双模式。

**已知限制**：明文密码仅在解密查看时于服务端内存短暂存活，用后即弃；导出文件含明文
密码，需妥善保管。

## 5. 批量导入导出

- **导入**：支持 xlsx / CSV，表头严格校验，提供标准模板下载；单次上限
  `IMPORT_MAX_ROWS`（默认 5000）行、`IMPORT_MAX_FILE_MB`（默认 10）MB。
- **导出**：支持 xlsx / CSV，含公式注入防护（前缀单引号转义）。
- **导入模板**：可在导入页动态生成下载。

**已知限制**：导入模板需严格匹配表头，否则校验失败并明确报错。

## 6. 项目分组

- 记录按项目归组；新建/编辑记录时仅可选择本人名下项目（已封堵越权访问）。
- 支持项目重命名。

## 7. 受控共享

- 按用户共享记录，权限分"只读 / 可编辑"，可设过期时间，随时撤销。
- 共享者不可变更记录的项目归属。
- 启动时自动清理已过期共享关系。

## 8. 密码健康审计

- **强度评分**：服务端批量评分，内置弱口令词典、序列、用户名 token 扣分。
- **重复检测**：跨条目重复密码检测。
- **年龄与到期**：口令使用天数分析，超龄阈值 `HEALTH_MAX_AGE_DAYS`（默认 365）。
- **态势评分**：五项告警汇总。
- **HIBP 泄露查询**：可选，默认随 `HIBP_ENABLED` 关闭（零外联）。开启后按 k-匿名协议
  仅发送口令 SHA-1 前 5 位，明文与完整摘要不出服务端。
- **报告**：四页签展示，支持 Excel 导出（**永不含密码列**）。
- **权限**：管理员可审计全库，普通用户仅本人数据。

**已知限制**：HIBP 查询依赖外网，关闭时报告页隐藏泄露页签。

## 9. API 密钥

- 创建 Bearer 密钥 `pmk_xxx`，**仅存 SHA-256 摘要**，明文仅创建时展示一次。
- 提供 REST API v1 记录增删改查。
- **明文查询限流**：reveal 按条数计 60 条/分钟/用户，单页明文上限 20。
- **来源限制**：支持来源 IP / CIDR 白名单。
- 支持启停管理。

**已知限制**：API 密钥接口豁免 CSRF（Bearer 鉴权），但仍受限流与白名单约束。

## 10. 审计日志

- 登录成功/失败、查看密码、导出、共享、锁定、TOTP 动作等全量留痕（含 IP/UA）。
- 管理员可按操作人筛选，分页查看（每页 `LOGS_PER_PAGE`，默认 50）。

## 11. 管理端

| 功能 | 说明 |
|---|---|
| 成员管理 | 解锁账户、重置口令、禁用、注销匿名化；分页（每页 `USERS_PER_PAGE`，默认 50） |
| 安全态势 | 安全状态总览，强制改密未完成时标红告警 |
| 系统控制台 | 系统信息、数据库大小、备份/恢复入口 |
| SMTP 在线配置 | 在线配置邮件服务，无需改 `.env` |
| 备份/恢复 | 一键备份数据库快照，支持从快照恢复；保留最近 `BACKUP_MAX_KEEP`（默认 10）份 |

**已知限制**：恢复操作会覆盖当前数据库，执行前请确认已备份。

## 12. 键盘快捷键

| 快捷键 | 功能 |
|---|---|
| `Alt+N` | 新建记录 |
| `Ctrl+F` | 聚焦站内搜索 |
| `/` | 聚焦搜索框 |
| `Alt+L` | 口令轮换页 |
| `Esc` | 收起内联表单 |

## 13. CLI 命令

`pip install -e .` 后，可通过 `flask --app wsgi` 调用以下命令（应用工厂注册）：

| 命令 | 说明 |
|---|---|
| `init-db` | 初始化/迁移数据库 |
| `create-admin` | 交互式创建管理员账户 |
| `purge-logs --days N` | 清理 N 天前的操作日志（默认 90） |
| `cleanup-shares` | 清理已过期的共享关系 |
