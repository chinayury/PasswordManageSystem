# 04 - 安全设计说明

> 更新日期：2026-11-14
> 适用：密码管理系统 PasswordManageSystem（PDM）

## 1. 安全架构

系统安全分为四层，由应用工厂 `create_app()`（`src/app/__init__.py`）统一装配：

1. **传输与响应层**：安全响应头（CSP / X-Frame-Options / nosniff / Referrer-Policy）、
   安全 Cookie、HTTPS 部署约束。
2. **认证与会话层**：Flask-Login 会话、强制改密拦截、会话纪元校验、空闲锁定、
   登录防爆破。
3. **数据层**：Fernet 应用层加密、bcrypt 口令哈希、输入校验、路径防护。
4. **审计与降级层**：全链路操作审计、密钥缺失拒绝启动、功能降级不崩溃。

## 2. 鉴权

- **动态码单次使用**：绑定验证器时记录首次匹配的时间步。登录和关闭两步验证都要求动态码的时间步晚于上次记录，因此并发请求也只能成功一次。时钟容差为前后一个时间步，记录以验证码实际匹配的时间步为准。实现依据见 [PyOTP 文档](https://pyauth.github.io/pyotp/#preventing-replay-attacks)。
- **会话鉴权**：基于 Flask-Login，未认证的页面请求 302 跳转登录页，AJAX/JSON/API
  请求返回 401 JSON。
- **强制改密拦截**：`must_change_password=1` 的账号登录后，除改密/登出/静态资源/
  健康检查外一律重定向到改密页。拦截器异常时 **fail-closed**（按需要改密处理，宁可
  多拦不放过）。
- **会话纪元校验**：改密/重置/注销递增 `users.session_epoch`，会话纪元落后即强制登出，
  实现"改密后其它设备全部下线"。区分"首次访问"与"记住我重新认证"两种无纪元情形，
  后者强制走一次完整登录，避免绕过踢下线。
- **权限校验**：管理端与审计功能按角色（管理员/普通用户）与数据归属（本人/全库）
  校验，越权访问（IDOR）已封堵。

## 3. 输入校验

- **表单校验**：WTForms 全站表单校验，字段类型、长度、格式严格约束。
- **记录搜索**：搜索字段白名单（`RECORD_SEARCH_FIELDS`），拒绝任意字段注入。
- **文件上传**：扩展名白名单（`ALLOWED_UPLOAD_EXTENSIONS`），大小受
  `MAX_CONTENT_LENGTH`（默认 20MB）限制。
- **Excel 解析**：defusedxml 防护 XML 实体扩张（billion laughs），装后自动生效。
- **导出防注入**：导出文件对公式前缀做转义，防 CSV/Excel 公式注入。
- **配置容错**：整数/浮点/日志级别等配置读取采用"非法值告警 + 回退 + 上下限钳制"，
  避免手滑写错导致启动崩溃。

## 4. 凭据管理

- **密钥缺失拒绝启动**：`SECRET_KEY` / `ENCRYPTION_KEY` 缺失或 `ENCRYPTION_KEY` 非法
  时，应用拒绝启动，绝不静默回退随机密钥（避免重启后存量密文不可解）。
- **密钥生成与持久化**：
  - 源码运行：首次启动在项目根生成 `.env`。
  - Docker 运行：入口脚本在 `data/.secrets.env` 生成并 `chmod 600`。
- **密钥备份约束**：`ENCRYPTION_KEY` 必须单独备份，丢失 = 已存密码永久无法解密。
  真实密钥文件（`.env` / `.secrets.env`）绝不入库、不入交付包。
- **敏感信息不入会话**：临时口令 / API 密钥明文不经 session cookie，使用进程内一次性
  机密仓（`src/app/services/onetime.py`）随机不透明 token 换取，阅后即焚。
- **API 密钥**：仅存 SHA-256 摘要，明文仅创建时展示一次。
- **口令哈希**：登录口令与恢复码使用 bcrypt；新版恢复码摘要使用 HMAC-SHA256。

## 5. 路径防护

- **可写目录解析**：`src/app/paths.py` 通过"向上查找项目根标记文件"定位项目根，
  兼容 src 布局与打包形态，避免路径漂移。
- **附件路径**：附件存储与读取均在 `UPLOAD_FOLDER` 内，文件名经唯一化处理，防路径
  穿越与覆盖。
- **备份路径**：备份快照仅在 `BACKUP_FOLDER` 内操作，恢复前校验快照来源。

## 6. 防爆破与限流

三层防护：

1. **内存限流**：IP 20 次/5 分钟、用户名 10 次/5 分钟。
2. **单账户锁定**：5 次失败锁 15 分钟。
3. **用户名+IP 持久化锁定**：10 次失败锁 15 分钟，重启不清零；锁定表行数硬上限 5 万
   + 幽灵用户名内存预算。

找回/注册接口验证码另有爆破限流。客户端 IP 解析：`TRUST_PROXY=true` 时取
`X-Forwarded-For` **末段**（防伪造首段绕过），默认不信任 XFF。

## 7. 安全响应头

- **CSP**：限制脚本/样式来源，防注入外联。
- **X-Frame-Options: DENY**：防点击劫持。
- **X-Content-Type-Options: nosniff**：防 MIME 嗅探。
- **Referrer-Policy**：控制来源信息泄露。
- **页面 no-store**：防密码等敏感内容残留缓存。

## 8. 降级策略

- **邮件功能**：SMTP 未配置时，注册/找回密码功能自动降级为明确报错，不崩溃。
- **HIBP 查询**：默认关闭（零外联）；关闭时报告页隐藏泄露页签，其余审计功能不受影响。
- **启动期维护**：过期共享清理、登录锁定清理、预恢复快照清理、僵尸健康审计轮次收敛
  等启动任务失败时记录日志，不阻断主流程。

## 9. 安全告警

- **不安全绑定告警**：服务绑定 `0.0.0.0`/`::` 且 `SESSION_COOKIE_SECURE=false` 时，
  启动打印醒目告警，提示二选一（仅本机 `HOST=127.0.0.1`，或前置 TLS 并开启安全 Cookie
  + `TRUST_PROXY`）。
- **调试模式告警**：`FLASK_DEBUG=1` 启动时打印"严禁用于对外生产环境"警告。

## 10. 能力边界（诚实声明）

本项目是自研自托管工具，**不可替代经过第三方专业审计的商用口令管理器**：

- 不承诺对抗已被攻陷的终端（终端上的明文口令可被本地窃取）。
- 不承诺对抗恶意管理员（管理员可访问数据库与密钥，具备最高权限）。
- 安全能力以代码与配置为准，部署方需按 [02-环境部署教程](02-环境部署教程.md)
  落实 HTTPS、密钥备份、访问控制等运维要求。
